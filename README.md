# Мой первый проект

## Проект: Avion - мебельный бренд

## Практическое занятие 1: Инициализация проекта
- Создание и настройка Git-репозитория
- Работа с системой контроля версий (коммиты, ветки)
- Настройка GitHub Pages для публикации сайта
- Создание базовой структуры проекта с README.md и .gitignore
- Оформление первого Pull Request и слияние веток

## Практическое занятие 2: HTML-разметка
- Создание семантической HTML5-разметки для мебельного сайта Avion
- Анализ и выбор макета для вёрстки
- Применение правильной иерархии заголовков
- Работа с типографом для корректного отображения текста
- Валидация HTML-кода через W3C Validator
- Создание навигационного меню, секций и футера

## Практическое занятие 3: CSS-стилизация
- Стилизация веб-страницы с использованием современных подходов
- Создание сброса стилей и базовых настроек
- Работа с CSS-переменными для цветов, шрифтов и размеров
- Подключение и настройка шрифтов Satoshi через Google Fonts
- Создание интерактивных элементов с состояниями (:hover, :focus)
- Применение методологии CSS для организации кода

## Практическое занятие 4: Адаптивная вёрстка
- Реализация адаптивной вёрстки с использованием Flexbox и Grid
- Создание Flexbox-меню для навигации
- Разработка Grid-сеток для контентных блоков и карточек товаров
- Реализация masonry-раскладки для нестандартных сеток
- Применение медиазапросов Desktop First
- Настройка адаптивности для 5 breakpoints (399px, 575px, 767px, 991px, 1199px)

## Практическое занятие 5: Мобильный интерфейс
- Проработка мобильного интерфейса согласно гайдлайнам HIG и Material Design
- Создание адаптивного гамбургер-меню для планшетов и мобильных устройств
- Разработка мобильных стилей с touch-friendly элементами
- Реализация фиксированной навигации для мобильной версии
- Добавление кнопки "Наверх" с плавной прокруткой
- Оптимизация размеров шрифтов для мобильных устройств
- Настройка доступности и обратной связи для пользовательских действий
